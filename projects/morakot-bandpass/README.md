# ERA5 850hPa 風場/比濕 帶通濾波檢視（10–30天 vs 30–90天）— 颱風莫拉克

逐日並排比較兩個時間尺度的季內振盪（Intraseasonal Oscillation）訊號：
ERA5 850hPa 風場與比濕的 10–30 天（bp13）與 30–90 天（bp39）帶通濾波結果，
用以檢視莫拉克颱風（Morakot, 2009，2009/08/05–08/09 侵台）前後大尺度環境的季內振盪配置。

**線上瀏覽：** 開啟 `index.html`（或透過 GitHub Pages）

- 左側：`data/bp13/` — 10–30 天帶通濾波，資料範圍 2009/07/01–08/20（51 天）
- 右側：`data/bp39/` — 30–90 天帶通濾波，資料範圍 2009/05/01–10/01（154 天）
- 預設開啟畫面停在颱風侵台日 2009/08/05

## 注意事項

- 兩個濾波的資料時間範圍不同：10–30 天濾波僅提供颱風前後約一個月資料，
  30–90 天濾波涵蓋較長期以呈現完整的季內振盪週期。時間軸上任一側顯示「此日期無資料」屬正常情況。
- 圖檔為 GrADS/COLA 繪製之 ERA5 再分析資料 850hPa 風場（向量）與比濕異常（填色，g/kg）。
