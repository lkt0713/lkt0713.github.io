# 颱風莫拉克 q3max 模擬 vs 中央氣象署雷達回波圖 對比

逐小時對照 ERA5-CE 模擬（`q3max`：柱狀最大混合比）與中央氣象署（CWA）台灣地區合成雷達回波觀測，
用來檢視模式對莫拉克颱風（Morakot, 2009）強降雨系統移動路徑與強度演變的掌握程度。

**線上瀏覽：** 開啟 `index.html`（或透過 GitHub Pages）

- 時間範圍：2009/08/05 08:00 – 2009/08/11 07:00（台灣當地時間），逐小時，共 144 個時間點
- 左側：`data/q3max/` — ERA5-CE 模式模擬，初始場 2009/08/03 00Z
- 右側：`data/radar/` — 中央氣象署颱風資料庫合成雷達回波圖（Radar_MOSA_CV）

## 注意事項

- 兩者物理量不同：q3max 為模式柱狀最大混合比（g/kg），雷達回波為觀測反射率（dBZ），色階亦不同。
  比對重點應放在**降雨/回波系統的空間位置、形狀與移動趨勢**，而非數值本身的直接對應。
- `data/radar/` 內的雷達回波圖取自中央氣象署颱風資料庫（<https://rdc28.cwa.gov.tw/TDB/>），
  該站台圖資原始用途為研究瀏覽/下載，此處僅作模式驗證教學/研究用途重新整理呈現，
  若有版權疑慮請自行向中央氣象署確認使用規範。
- q3max 資料時間範圍為 2009/08/03–08/11，但氣象署僅公開颱風警報期間（08/05 起）的雷達圖，
  故 08/03–08/05 這段沒有觀測雷達可比對，未收錄於本站。
